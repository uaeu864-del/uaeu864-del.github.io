Privacy Policy — W360 Uploader

Last updated: 15 November 2026

W360 Uploader is a private tool used only by the W360 News channel to manage its own accounts. It is not offered to the public.

What data it accesses

With the account owner's permission, it uses Google APIs (YouTube Data API, YouTube Analytics API and Google Drive API) to upload the channel's own videos, set their details, read the channel's own analytics, and upload video files to the channel's own Google Drive folder.

How data is used and stored

Data is used only to perform those actions for the channel. It is not sold, shared with third parties, or used for advertising. Access tokens are stored privately and never published.

Google API Services User Data Policy

W360 Uploader's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be removed at any time at https://myaccount.google.com/permissions.
